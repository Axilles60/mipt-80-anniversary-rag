## Предметные сценарии

Для каждого ID способ проверки — локально задать вопрос и сверить каждый вывод с оригиналом по процедуре владельца. Фактический результат для всех строк: **не подтверждено**. Блокер: оригиналы не разрешено обрабатывать в Codex; поиск, применимость редакций и предметная полнота на реальном корпусе не проверены. Ссылка ведёт к условиям конкретного сценария в SDD.
