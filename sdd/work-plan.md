## Правила цикла (сохраняются)

Воспроизвести через штатный импорт и `POST /ask` → регрессионный тест → исправление по содержанию/структуре, без привязки к номерам SRC и дословным вопросам → тесты, сквозная, процедуры, гибрид на одинаковых данных → журнал и коммит. Набор, повлиявший на правку, становится настроечным; для оценки — новый, прогоняется один раз. Существующие отчёты не перезаписываются.
